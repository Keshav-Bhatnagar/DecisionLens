# Sample Audio Examples

This directory contains reference audio files for testing speech-to-text (STT) and media ingestion workflows in DecisionLens.

- `sample_decision_meeting.wav`: 10-second reference 16kHz mono audio generated via ffmpeg lavfi synthesizer, suitable for testing upload, ffmpeg probing, and transcription pipelines.
- You can also upload any `.wav`, `.mp3`, `.m4a`, or `.mp4` recording through the `/media/upload` API endpoint.
